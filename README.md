## Flagship Project

### [zspace-cli](https://github.com/skyzhao1223/zspace-cli)

CLI, SDK & MCP Server for **ZSpace (极空间) NAS** — manage files from terminal, Python scripts, or AI agents. Zero config, no SSH needed.

```bash
pip install zspace-cli
zs check   # ✓ Connected
zs ls      # List NAS files
```
